# Задача 6: Циклическое заполнение без срабатывания триггеров ошибки

## 📋 Описание проблемы

**Симптом:** После submit форма перерисовывается с ошибкой (регистрация закрыта — открывается форма входа), но в логах нет детекции ошибки — процесс продолжается по кругу до `max_steps_exceeded`.

**Пример из лога:**
```
22:33:42 | === Заполнение полей завершено: заполнено=['confirm_email', 'password'], пропущено=['username', 'email', 'website', 'comment', 'captcha'] ===
22:33:47 | Размер body.innerHTML после submit: 54058 симв.
22:33:48 | Блок 'input' изменился после submit — было 2 элементов, стало 8
22:33:48 | Блок 'input' изменился, на странице есть поля — продолжаем регистрацию
                                                                ↑
                                                ⚠️ _check_result() НЕ ВЫЗЫВАЕТСЯ!

22:34:11 | Блок 'input' не изменился после submit — пробуем следующий блок
22:34:17 | Блок 'input' изменился после submit — было 2 элементов, стало 8
22:34:31 | Достигнут лимит шагов — запрашиваем ручное подтверждение
22:34:39 | User buxarnet failed: max_steps_exceeded
```

**В браузере:** Форма входа вместо регистрации (регистрация закрыта на форуме)

**В логах:** Нет проверки индикаторов ошибки → цикл продолжается 5 раз до лимита

---

### 🐛 Корневая причина

**В `_check_block_changed()` (строки 720-745 в `registration_controller.py`):**

```python
if same_block is None:
    logger.debug(
        f"Блок '{form_selector}' после submit не найден — изменение обнаружено"
    )
    return True, has_any_fields, new_blocks  # ← НЕТ сравнения snapshot!
```

**Проблема:** Когда `same_block is None` (селектор формы не совпал) — код **сразу возвращает `block_changed=True`** без сравнения состава полей.

**Почему snapshot нестабильный (2→8 или 2→2 элементов):**

| Этап | Полей в snapshot | Почему |
|------|------------------|--------|
| **До submit** | 2 поля | `confirm_email` + `password` (заполненные) |
| **После submit (шаг 1)** | 8 полей | 2 + `website` + `comment` + `captcha` + `username` + `email` + `submit` |
| **После submit (шаг 2)** | 2 поля | Оператор пропустил custom_fields → только 2 заполненных |

**Результат:**
- Шаг 1: 2 ≠ 8 → `block_changed=True` → ветка `continue` без `_check_result()`
- Шаг 2: 2 = 2 → `block_changed=False` → ветка `next block`
- `_check_result()` **никогда не вызывается** → ошибка не детектируется

## 📄 Нужная часть кода (registration_controller.py)

**Текущая реализация `_check_block_changed()` (строки 705-745):**

```python
async def _check_block_changed(
    self,
    snapshot: frozenset[tuple[str, str, str, str, str]],
    form_selector: str,
    template: dict | None,
) -> tuple[bool, bool, list[dict]]:
    """Проверяет изменился ли блок после submit."""
    new_blocks = await self.selector_finder.analyze_current_page(template=template)
    has_any_fields = bool(new_blocks)

    # Ищем тот же блок по form_selector
    same_block = next(
        (b for b in new_blocks if b["form_selector"] == form_selector),
        None,
    )

    if same_block is None:
        logger.debug(
            f"Блок '{form_selector}' после submit не найден — изменение обнаружено"
        )
        return True, has_any_fields, new_blocks  # ← ПРОБЛЕМА ЗДЕСЬ!

    # Блок есть — делаем новый снимок и сравниваем
    new_selectors = await self._get_selectors_for_block(
        template=template,
        block=same_block,
    )
    new_snapshot = self._make_block_snapshot(new_selectors)

    if new_snapshot != snapshot:
        logger.debug(
            f"Блок '{form_selector}' изменился после submit — "
            f"было {len(snapshot)} элементов, стало {len(new_snapshot)}"
        )
        return True, has_any_fields, new_blocks

    logger.debug(
        f"Блок '{form_selector}' не изменился после submit — "
        f"пробуем следующий блок"
    )
    return False, has_any_fields, new_blocks
```

## ✅ Предлагаемое решение

**Добавить сравнение snapshot по количеству + типы полей когда `same_block is None`:**

```python
if same_block is None:
    # ← НОВОЕ: Если селектор изменился — сравниваем snapshot первого блока
    if new_blocks:
        new_selectors = await self._get_selectors_for_block(
            template=template,
            block=new_blocks[0],
        )
        new_snapshot = self._make_block_snapshot(new_selectors)
        
        # Сравниваем по составу полей (количество + типы)
        if len(snapshot) == len(new_snapshot):
            old_types = {item[0] for item in snapshot}
            new_types = {item[0] for item in new_snapshot}
            
            if old_types == new_types:
                # Типы совпали — это та же страница (возможно с ошибкой)
                logger.debug(
                    f"Блок '{form_selector}' не найден, но состав полей совпадает "
                    f"({len(snapshot)} полей, типы={old_types}) — форма вернулась с ошибкой"
                )
                return False, has_any_fields, new_blocks  # ← block_changed=False!
            else:
                # Типы разные — это новая страница
                logger.debug(
                    f"Блок '{form_selector}' не найден, типы полей изменились "
                    f"({old_types} → {new_types}) — переход к следующему шагу"
                )
                return True, has_any_fields, new_blocks
        else:
            # Количество разное — это новая страница
            logger.debug(
                f"Блок '{form_selector}' не найден, количество полей изменилось "
                f"({len(snapshot)} → {len(new_snapshot)}) — переход к следующему шагу"
            )
            return True, has_any_fields, new_blocks
    
    # Нет блоков — изменение обнаружено
    logger.debug(f"Блок '{form_selector}' после submit не найден — изменение обнаружено")
    return True, has_any_fields, new_blocks
```
