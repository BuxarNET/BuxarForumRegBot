# Задача 5: Ошибка в логике определения "изменился блок или нет"

## 📋 Описание проблемы

**Симптом:** После submit форма перерисовывается с ошибкой (например "Имя должно быть уникальное"), но в логах нет детекции ошибки регистрации — процесс продолжается без обработки триггеров проверки результата.

**Пример из лога:**
```
2026-03-24 15:54:48 | INFO | controllers.registration_controller:1595 | 
    === Заполнение полей завершено: заполнено=['confirm_email', 'password', ...] ===

2026-03-24 15:54:53 | DEBUG | controllers.registration_controller:720 | 
    Блок 'input' после submit не найден — изменение обнаружено

2026-03-24 15:54:53 | INFO | controllers.registration_controller:311 | 
    Блок 'input' изменился, на странице есть поля — продолжаем регистрацию
                                                                 ↑
                                                                 │
                                                  ⚠️ ПРОВЕРКА _check_result() НЕ ВЫЗЫВАЕТСЯ!
```

**В браузере:** Ошибка "Имя должно быть уникальное" (форма перерисовалась с ошибкой)

**В логах:** Нет сообщения об ошибке регистрации → процесс продолжается

---

### 🐛 Корневая причина

**В `_check_block_changed()` (строки 865-920 в `registration_controller.py`):**

```python
same_block = next(
    (b for b in new_blocks if b["form_selector"] == form_selector),
    None,
)

if same_block is None:
    # ← ВОТ ЗДЕСЬ ПРОБЛЕМА!
    # Если селектор изменился — сразу возвращаем block_changed=True
    # Без сравнения состава полей (количество + типы)
    logger.debug(f"Блок '{form_selector}' после submit не найден — изменение обнаружено")
    return True, has_any_fields, new_blocks
```

**Почему селектор изменился:**

| Шаг | form_selector | Почему |
|-----|---------------|--------|
| **1** | `#pageLogin` | Форма с `id="pageLogin"` |
| **2** | `input` | Форма без `id` → fallback на tagName |

**Результат:**
- `same_block = None` (селекторы не совпали)
- `block_changed = True` → код считает что это **следующий шаг регистрации**
- `_check_result()` **не вызывается** → ошибка не детектируется

## ✅ Согласованный план решений

### Пункт 1: Добавить сравнение snapshot по количеству + типы полей

**Файл:** `src/controllers/registration_controller.py` → `_check_block_changed()`

**Что делаем:**
- Если `same_block is None` — **не возвращать сразу `True`**
- Взять первый блок из `new_blocks` и создать его snapshot
- Сравнить старый и новый snapshot по:
  1. **Количество полей** (`len(snapshot)`)
  2. **Типы полей** (`{item[0] for item in snapshot}` — field_name)
- Если количество **И** типы совпали — это **та же страница (возможно с ошибкой)** → `block_changed=False`
- Если количество **ИЛИ** типы разные — это **новая страница** → `block_changed=True`

**Логика проверки:**
```python
if same_block is None:
    # ← НОВОЕ: Если селектор изменился — сравниваем snapshot первого блока
    if new_blocks:
        new_selectors = await self._get_selectors_for_block(
            template=template,
            block=new_blocks[0],
        )
        new_snapshot = self._make_block_snapshot(new_selectors)
        
        # Сравниваем по составу полей (количество + типы)
        if len(snapshot) == len(new_snapshot):
            # Количество совпадает — проверяем типы
            old_types = {item[0] for item in snapshot}  # field_name
            new_types = {item[0] for item in new_snapshot}
            
            if old_types == new_types:
                # Типы совпали — это та же страница (возможно с ошибкой)
                logger.debug(
                    f"Блок '{form_selector}' не найден, но состав полей совпадает "
                    f"({len(snapshot)} полей, типы={old_types}) — форма вернулась с ошибкой"
                )
                return False, has_any_fields, new_blocks  # ← block_changed=False!
            else:
                # Типы разные — это новая страница
                logger.debug(
                    f"Блок '{form_selector}' не найден, типы полей изменились "
                    f"({old_types} → {new_types}) — переход к следующему шагу"
                )
                return True, has_any_fields, new_blocks
        else:
            # Количество разное — это новая страница
            logger.debug(
                f"Блок '{form_selector}' не найден, количество полей изменилось "
                f"({len(snapshot)} → {len(new_snapshot)}) — переход к следующему шагу"
            )
            return True, has_any_fields, new_blocks
    
    # Нет блоков — изменение обнаружено
    logger.debug(f"Блок '{form_selector}' после submit не найден — изменение обнаружено")
    return True, has_any_fields, new_blocks
```

**Преимущества:**
- ✅ Детектирует ошибки даже когда форма перерисовывается на той же странице
- ✅ Не ломает существующую логику перебора блоков
- ✅ Работает с динамическими селекторами (XenForo без `id`)
- ✅ Минимальное изменение — только `_check_block_changed()`
