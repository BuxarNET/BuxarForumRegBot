# Задача 3: Лишние динамические селекторы пароля добавляются в шаблон при каждом запуске

## Описание проблемы

При каждом запуске регистрации на форуме XenForo в шаблон добавляются
новые селекторы пароля с динамическими ID вида `#ctrl_<хэш>`:

```json
"password": [
    "input[name='password']",
    "#ctrl_pageLogin_password",
    "#ctrl_eb141216267ee54391095376e5c5fa40",
    "#ctrl_996bd4e13eb24a2be11ea7fb1f6078e1"
],
"confirm_password": [
    "input[name='password_confirm']",
    "#ctrl_996bd4e13eb24a2be11ea7fb1f6078e1",
    "#ctrl_6fe2d76f203f5d251fb639eba4e3a4af",
    "#ctrl_7f996cc8f816930ffc726a4e9238a273"
]
```

Селекторы вида `#ctrl_<хэш>` — динамические ID полей второй страницы
регистрации XenForo (`register/register`). Они генерируются случайно
при каждой сессии и не должны сохраняться в шаблон — при следующем
запуске эти ID уже недействительны.

Проблема является регрессией после последних изменений в логике
сохранения селекторов в шаблон.
