# Задача 1: Поддержка разделённых полей даты рождения (dob_day / dob_month / dob_year) - рассматриваем разные варианты на разных форумах

## Описание проблемы

Форумы типа XenForo разбивают дату рождения на три отдельных поля:

```html
<select name="dob_month">...</select>
<input type="text" name="dob_day" placeholder="День" />
<input type="text" name="dob_year" placeholder="Год" />
```

Текущая логика `identify_fields` определяет все три поля как `birthdate`
по ключевым словам (`dob` совпадает с `birthdate_keywords`) и добавляет
их в `custom_fields` с одним именем. В результате:

- Все три поля получают одно значение `"01.09.1990"` из профиля
- `dob_month` (`<select>`) не находится — неверный селектор `input[name='dob_month']`
- `dob_day` и `dob_year` заполняются полной строкой `"01.09.1990"` вместо `"1"` и `"1990"`
- Скрипт запрашивает ручной ввод вместо автозаполнения

Другие форумы могут иметь другие значения, тоже нужно проработать варианты.

### Лог ошибки

```
Заполняем дополнительное поле: birthdate (input[name='dob_month'])
Пробуем вариант '01.09.1990' для 'birthdate' из профиля

Пробуем вариант '01.09.1990' для 'birthdate' из профиля

Пробуем вариант '01.09.1990' для 'birthdate' из профиля
Введён текст: 01.09.1990   ← неверное значение
```
